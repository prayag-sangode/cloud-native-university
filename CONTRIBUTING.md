# Contributing to Cloud Native University

Thank you for your interest in contributing!

Cloud Native University is a free, community-driven initiative focused on making Cloud, DevOps, and Cloud Native learning simple, practical, and hands-on.

---

# How You Can Contribute

You can contribute in the following ways:

## 1. Improve Labs
- Add new hands-on labs
- Improve existing steps
- Fix errors or unclear instructions

## 2. Improve Documentation
- Enhance READMEs
- Add missing explanations
- Improve architecture diagrams

## 3. Add Real-World Examples
- Production use cases
- Troubleshooting scenarios
- Best practices from industry

## 4. Fix Issues
- Typo corrections
- Broken commands
- Incorrect configurations

## 5. Add New Learning Content
- New labs
- New Kubernetes examples
- AWS / Docker / DevOps scenarios

---

# Contribution Guidelines

## Step 1: Fork the Repository
Click "Fork" on GitHub.

## Step 2: Clone Your Fork

```bash
git clone https://github.com/<your-username>/cloud-native-university.git
````

## Step 3: Create a Branch

```bash
git checkout -b feature/your-feature-name
```

## Step 4: Make Changes

Follow the structure:

* Each module should contain:

  * README.md
  * architecture.md
  * troubleshooting.md
  * best-practices.md
  * labs/

## Step 5: Commit Changes

```bash
git add .
git commit -m "Add: <your meaningful message>"
```

## Step 6: Push Changes

```bash
git push origin feature/your-feature-name
```

## Step 7: Create Pull Request

Open a PR to the main repository.

# Content Standards

## Keep it Simple

* Avoid over-complicated explanations
* Focus on clarity

## Keep it Practical

* Every concept should include a lab or example

## Keep it Real-World

* Use production-like scenarios whenever possible

---

# What NOT to Do

* Do NOT remove existing structure
* Do NOT add unrelated content
* Do NOT submit incomplete labs
* Do NOT break formatting consistency

---

# Lab Writing Format

Each lab should include:

```text
Title
Objective
Prerequisites
Steps
Expected Output
Troubleshooting
```
