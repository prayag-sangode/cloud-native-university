# Linux for Cloud & DevOps Engineers

## Goal

Understand how Linux works so you can confidently run and troubleshoot applications in cloud environments like AWS and Kubernetes.

---

# Why Linux Matters

In real production systems:

- AWS EC2 runs Linux
- Docker runs on Linux kernel
- Kubernetes nodes are Linux machines
- CI/CD pipelines run on Linux agents

If Linux breaks → everything breaks.

---
