# Cloud Native University

A free hands-on learning platform for Cloud, DevOps, and Cloud Native technologies.

Built for engineers to learn:

- Linux fundamentals
- Docker & containers
- Kubernetes
- AWS & EKS
- GitOps (ArgoCD)
- Observability (Prometheus & Grafana)
- Security (Kyverno)

---

## What This Is

This is not theory-heavy content.

It is:
- Hands-on labs
- Real-world workflows
- Workshop-based learning
- Production-style architecture understanding

Cloud Native Platform Engineering Bootcamp
