# Cloud Native University Roadmap

## Vision

Cloud Native University is a free, hands-on learning platform designed to help engineers understand and build real-world cloud-native systems using:

- Linux
- Docker
- Kubernetes
- AWS
- EKS
- GitOps
- Observability
- Security

The goal is simple:

> Learn by building real systems, not just reading theory.

---

# Learning Phases

## Phase 1: Foundations (Core Engineering Skills)

Focus: Understanding how systems work at the OS and network level.

Modules:
- 01 Linux
- 02 Networking
- 03 Docker

### Outcome:
You will understand:
- How applications run on Linux
- How networks and ports work
- How containers package applications

---

## Phase 2: Kubernetes Core

Focus: Running applications at scale.

Modules:
- 04 Kubernetes
- 05 Helm

### Outcome:
You will understand:
- Container orchestration
- Deployments, services, pods
- Packaging Kubernetes apps

---

## Phase 3: Cloud (AWS + EKS)

Focus: Running workloads in real cloud environments.

Modules:
- 06 AWS
- 07 EKS

### Outcome:
You will understand:
- Cloud infrastructure basics
- IAM, VPC, EC2
- Managed Kubernetes (EKS)

---

## Phase 4: GitOps + Delivery

Focus: Modern deployment workflows.

Modules:
- 08 ArgoCD

### Outcome:
You will understand:
- GitOps principles
- Continuous delivery to Kubernetes
- Declarative deployments

---

## Phase 5: Observability

Focus: Monitoring real systems.

Modules:
- 09 Prometheus
- 10 Grafana

### Outcome:
You will understand:
- Metrics and monitoring
- Dashboards
- Alerting systems

---

## Phase 6: Security

Focus: Policy and governance in Kubernetes.

Modules:
- 11 Kyverno

### Outcome:
You will understand:
- Kubernetes security policies
- Admission control
- Policy enforcement

---

##  Phase 7: Capstone Project

Module:
- 12 Capstone Project

### Final System:

GitHub → ArgoCD → EKS → Application → Prometheus → Grafana → Kyverno

### Outcome:
You will build a production-like cloud native platform.

---

# Flagship Program

## Cloud Native Platform Engineering Bootcamp

A 1-day workshop covering:

- Linux → Docker → Kubernetes
- AWS → EKS
- GitOps (ArgoCD)
